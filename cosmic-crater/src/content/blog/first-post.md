<h3>1.2 Restaurant Menu Page</h3>
<section>
<p>Shows the menu of a selected restaurant with available food items.</p>

<h3>1.3 Item Size and Ingredients Selection Page</h3>
<p>Allows users to customize their order by selecting item size and ingredients.</p>

<h3>1.4 Shopping Cart Page</h3>
<p>Displays selected items and allows users to modify their order before checkout.</p>

<h3>1.5 Checkout Page</h3>
<p>Finalizes the order, enabling users to enter payment and delivery details.</p>

<h3>1.6 Update Delivery Address Page</h3>
<p>Provides users the option to change their delivery address before order submission.</p>

<h3>1.7 Order Success Page</h3>
<p>Confirms a successful order submission and provides order details.</p>

<h3>1.8 Order Error Page</h3>
<p>Displays an error message if there is an issue processing the order.</p>

<h3>1.9 My Orders Page</h3>
<p>Lists past and current orders for the logged-in user.</p>

<h3>1.10 Open Orders Page (Delivery Drivers Only)</h3>
<p>Shows active delivery orders available for delivery drivers.</p>

<h3>1.11 Administrator Control Panel Page</h3>
<p>Provides admins with tools to manage restaurants, menu items, and ingredients.</p>
</section>
